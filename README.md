# Frontend UI Project

Projeto de interface desenvolvido com HTML, CSS e JavaScript.

## Tecnologias
- HTML
- CSS
- JavaScript

## Preview
Este projeto é um estudo de interface de páginas de acesso (login e cadastro), utilizando HTML, CSS e JavaScript.  
Os dados de cadastro são armazenados no Local Storage do navegador e a aplicação utiliza eventos JavaScript para controlar as interações dos botões e validações básicas dos formulários.
